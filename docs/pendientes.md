# Trabajo que requiere revisión adicional

Esta entrega incluye un personaje vestido, con materiales, rig FK, poses de
prueba y renders. Es una versión editable de presentación, no un personaje
certificado para una producción de animación.

- Ajustar parecido facial y perfil comparando directamente las fotos. La cara
  es una interpretación procedural, no una reconstrucción fotogramétrica.
- Refinar la silueta del peinado y reducir su lectura de mechones uniformes.
- Retopología facial con loops para párpados/boca, cavidad oral y rig de mandíbula.
- Pintar pesos y crear correctivos para hombros, codos y dedos.
- Resolver faldones y capas al sentarse/agacharse; añadir controles de tela.
- Mejorar pliegues del pantalón y mangas, y acabado de las uniones de prendas.
- Revisar UV para pintura; hornear mapas si el destino es un motor externo.
- Crear IK y un ciclo de caminata cuando sean necesarios.

La aprobación visual del parecido corresponde al usuario. Los informes
automáticos sólo verifican propiedades medibles de la escena.
